# Τοπική εκκίνηση Namelecule σε macOS

Διπλό κλικ στο **Namelecule** στην Επιφάνεια Εργασίας. Ανοίγει την υποδοχή της
κύριας έκδοσης στο Firefox και ξεκινά τον τοπικό server, ανεξάρτητα από VS Code.
Ο server μένει ενεργός όταν κλείσει το εικονίδιο και σταματά με την έξοδο από
τον λογαριασμό ή την επανεκκίνηση του υπολογιστή.

Ο launcher χρειάζεται το `/usr/bin/python3`, το Firefox στο Applications και
τον φάκελο του έργου στην αποθηκευμένη θέση. Δεν τροποποιεί την εφαρμογή ή τη
React έκδοση. Οι υπάρχουσες διαδικτυακές εξαρτήσεις της εφαρμογής παραμένουν.
Αν μετακινηθεί ο φάκελος του έργου, χρειάζεται αναδημιουργία του εικονιδίου.

Το εικονίδιο χρησιμοποιεί μόνο το μόριο από το υπάρχον λογότυπο
`design/assets/namelecule-methane-v1.png`, με διατήρηση αναλογιών και διαφάνειας,
ώστε να διακρίνεται στις μικρές διαστάσεις της Επιφάνειας Εργασίας. Το όνομα
Namelecule παραμένει η ετικέτα του εικονιδίου. Το αρχικό λογότυπο δεν αλλάζει.
Το `make-icon.js` και τα εργαλεία macOS δημιουργούν τις αναλύσεις του `.icns`.

Πηγές: `launch.applescript`, `launcher.py`, `build-app.py`, `make-icon.js`. Δημιουργία από το έργο:

```sh
/usr/bin/python3 -B tools/namelecule-launcher/build-app.py "$HOME/Desktop/Namelecule.app"
```

Η δημιουργία αρνείται να αντικαταστήσει υπάρχον αρχείο. Η δέσμη περιέχει δικό
της αντίγραφο του helper και τη διαδρομή του έργου στο `Contents/Resources`.
Ο server ακούει μόνο στο `127.0.0.1`. Επαναχρησιμοποιεί δικό του server για το
ίδιο έργο. Αν η 8013 είναι κατειλημμένη, δοκιμάζει έως την 8032 χωρίς να κλείνει
άλλα προγράμματα. Προσωρινό lock και log αποθηκεύονται στο
`~/Library/Caches/Namelecule`. Τυχόν αποτυχία εμφανίζεται με παράθυρο διαλόγου.
Το macOS μπορεί να ζητήσει πρόσβαση στην Επιφάνεια Εργασίας για να διαβαστεί
ο φάκελος της εφαρμογής. Η δέσμη αποκτά τοπική ad-hoc υπογραφή μετά την
προσθήκη των πόρων της· δεν πρόκειται για δημοσίευση ή notarization.

Έλεγχοι του helper σε προσωρινούς φακέλους/θύρες (με αυτόματο καθαρισμό):

```sh
/usr/bin/python3 -B tools/namelecule-launcher/test-launcher.py
```

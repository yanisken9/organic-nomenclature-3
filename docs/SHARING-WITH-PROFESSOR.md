# Ανασκόπηση της δουλειάς του Γιάννη

Το προσωπικό fork είναι https://github.com/yanisken9/organic-nomenclature-3.
Ο κλάδος εργασίας είναι `thesis-work`. Η αρχική έκδοση προέρχεται από το
https://github.com/nick-charistos/organic-nomenclature-3, βάση `9c5259e`.

Οι αλλαγές αφορούν την ταυτότητα **Namelecule**, την εμφάνιση της εφαρμογής,
την προσαρμογή του πλαισίου 3D και τις εκκρεμείς ρυθμίσεις τίτλων σεναρίων.
Αναλυτική καταγραφή υπάρχει στο `docs/YANNIS-CONTRIBUTIONS.md`.
Ο Γιάννης επιβεβαίωσε ότι η προσαρμογή 3D λειτουργεί στο `αλκάνια.json`.

Για τοπική δοκιμή: checkout του `thesis-work`, εκτέλεση
`python3 -m http.server 8001 --bind 127.0.0.1` από τη ρίζα, και άνοιγμα του
`http://127.0.0.1:8001/mulermoc-nom-44.html` σε browser.
Η εφαρμογή χρειάζεται σύνδεση δικτύου για τις βιβλιοθήκες από CDN.

Το fork και ο κλάδος επιτρέπουν ανεξάρτητη ανασκόπηση. Καμία αλλαγή δεν
μεταφέρεται στο αποθετήριο του καθηγητή χωρίς ξεχωριστή συγχώνευση.
Δεν έχει ενεργοποιηθεί ξεχωριστό GitHub Pages από αυτή τη διαδικασία.

Τοπικές συνδέσεις Git: `origin` = fork Γιάννη, `upstream` = αρχικό έργο.
Για αποστολή χρησιμοποιούμε ρητά `git push origin thesis-work`.

# Εμπλουτισμός αλκανίων για τα τέσσερα παιχνίδια — πλάνο 16/11/2026

**Κατάσταση: πρόταση προς έγκριση. Δεν έχει αλλάξει κώδικας ή core.** Ο χρήστης έθεσε πλέον πρώτο τον εμπλουτισμό της δεξαμενής. Ακολουθούν η ενσωμάτωση τεσσάρων παιχνιδιών, τα επίπεδα, τα άλλα μαθήματα και οι προτάσεις μορίων ανά μάθημα.

## Πρώτη παρτίδα

| Νέο μόριο | Παιδαγωγική χρησιμότητα |
| --- | --- |
| 2-μεθυλοβουτάνιο | Μικρό παράδειγμα μίας διακλάδωσης |
| 3-μεθυλοπεντάνιο | Κεντρική διακλάδωση και συμμετρία |
| 3-αιθυλοπεντάνιο | Αιθυλομάδα με δύο άτομα C και ισοδύναμες κύριες αλυσίδες |
| 2,2-διμεθυλοπροπάνιο | Δύο μεθυλομάδες στην ίδια θέση και άτομο C χωρίς H στο Παζλ |
| 2,2-διμεθυλοβουτάνιο | Σύγκριση της συνδεσμολογίας 2,2- με το υπάρχον ισομερές 2,3-διμεθυλοβουτάνιο |
| 3-αιθυλο-2-μεθυλοπεντάνιο | Δύο είδη αλκυλίων, αλφαβητική σειρά και επιλογή επιλέξιμης αλυσίδας |

Σύνολο **14 αλκάνια**, με προσωρινή δομική κατανομή **5 / 4 / 5** χωρίς διακλάδωση / μία / περισσότερες. Αυτό δεν αποτελεί ακόμη τελικό ορισμό επιπέδων δυσκολίας. Η ενεργή βιβλιοθήκη θα έχει 147 μόρια. Τα έξι ελέγχθηκαν με 60 αναλύσεις στη μνήμη, σε πέντε μηχανές με ρητά/έμμεσα H· ονόματα, συνθετικά και επιλέξιμες αλυσίδες συμφώνησαν. Τα έξι είναι συντακτικά μη χειρόμορφα· η γεωμετρία 3D δεν έχει ακόμη πιστοποιηθεί.

Οι επίσημες πηγές και τα CID βρίσκονται στο [αναλυτικό πλάνο](checks/four-games-roadmap-preflight-20261116/pool-first-plan.json). Ο έλεγχος διαθεσιμότητας επίσημων PubChem 3D SDF επέστρεψε έξι HTTP200/V2000. Δεν έχει γίνει εισαγωγή τους στα δεδομένα του έργου.

## Συγκεκριμένη εφαρμογή

1. Επιμελημένη κοινή πηγή για τα έξι μόρια: τρεις 2D μορφές, τεκμηριωμένο 3D και προέλευση. Παραγόμενο κοινό JS μέσω του υπάρχοντος `nameExamplesCustom`.
2. Ίδια νέα δεδομένα στην ενεργή Main57 και στους παραγόμενους απομονωμένους viewers Builder55/Detective56, διατηρώντας τα παλιά αρχεία δεδομένων και cores.
3. Χωριστός version2 κατάλογος παιχνιδιών με τα 14. Ο σημερινός κατάλογος οκτώ, οι υπογραφές και οι παλιές προσπάθειες παραμένουν αναπαραγώγιμες με τη δική τους έκδοση. Οι νέες standalone προσπάθειες χρησιμοποιούν τη νέα δεξαμενή.
4. Ενημέρωση loaders, SVG του Συνεργείου και των επιτρεπόμενων στόχων του Ντεντέκτιβ, ώστε τα μόρια να παίζονται πραγματικά και στα τέσσερα παιχνίδια. Οι επιλέξιμες αλυσίδες και οι στόχοι μεθυλίου/αιθυλίου παράγονται από επαληθευμένο γράφο και γενικά κριτήρια, χωρίς εξαιρέσεις συγκεκριμένων atom IDs.
5. Η εισαγωγή σε υποχρεωτικές στάσεις και η επιλογή επιπέδων θα ακολουθήσουν στην επόμενη ενότητα. Το σημερινό JSON αλκανίων και η κερδισμένη πρόοδος δεν αλλάζουν σε αυτή την παρτίδα.

Τα **17 υπάρχοντα paths** και τα **48 νέα paths δεδομένων/εργαλείων/εικόνων** αναγράφονται ακριβώς στο JSON, μαζί με before-hashes. Περιλαμβάνουν την ενεργή Main57, τα τέσσερα standalone HTML/controllers, τους δύο host generators και generated HTML, τον provider/κατάλογο κουίζ, τη μηχανή/bridge Ντεντέκτιβ και νέα αρχεία δεδομένων, MOL/SDF, SVG και provenance. Δεν προβλέπεται αλλαγή core, React ή των source Main55/56.

## Αποδοχή

Χημική ταυτότητα και σωστά σθένη των πραγματικών εισαγόμενων αρχείων, όλες οι ισότιμες αλυσίδες/ομάδες, απόρριψη λανθασμένων ή κενών στόχων, πραγματική επίλυση κάθε νέου μορίου σε κάθε παιχνίδι, τρεις αναπαραστάσεις/3D όπου παρέχεται, zoom/resize/κάδρο, ομαλή επαναφορά παλιών receipts και αμετάβλητες σημερινές στάσεις αλκανίων. Ο Ντεντέκτιβ πρέπει να καλύπτει και τα τέσσερα ήδη υπάρχοντα αλκάνια που λείπουν από το πρωτότυπο· στο μεθάνιο δεν δημιουργείται κενή αποστολή δεσμών μεταξύ ατόμων C.

Θα ακολουθήσουν έλεγχος πραγματικών αρχείων από Chemistry Validator και ανεξάρτητος Reviewer σε παγωμένο diff. Δεν δηλώνεται συνεδριακή/offline ή Firefox qualification. Δεν περιλαμβάνονται commit, δημοσίευση ή πλήρης εξωτερική αποθήκευση.

# Σκελετικοί τύποι αλκινίων χωρίς C — 22/10/2026

Ο χρήστης ζήτησε να μη φαίνονται σύμβολα C στους σκελετικούς τύπους όλων
των αλκινίων, όπως στα αλκένια, και ενέκρινε το σχέδιο πριν την υλοποίηση.

Η διόρθωση εφαρμόζεται στα τέσσερα διαθέσιμα αλκίνια: προπίνιο,
1-βουτίνιο, 2-βουτίνιο και 3-μεθυλο-1-βουτίνιο.

## Αιτία και αλλαγή

Ο JSME εμφανίζει αυτόματα C σε συνευθειακούς άνθρακες. Οι γραμμές των δεσμών
φτάνουν ήδη στα σωστά κέντρα, αλλά πίσω από κάθε C υπάρχει ένα μικρό πλαίσιο
που τις καλύπτει. Δεν απαιτείται μετακίνηση ατόμων ή επέκταση γραμμών.

Προστέθηκε η `fHideAlkyneSkeletalCarbons` στο
`js/mulermoc-nom-molview-49.js`, μέσα στη διαδρομή `fUpdateSVG`.
Στη λειτουργία `skeletal`, όταν η ταξινόμηση είναι `alkynes`, αφαιρεί τα
κείμενα C και τα αμέσως προηγούμενα στρογγυλεμένα πλαίσιά τους.
Οι ξεχωριστές ελλείψεις/πολύγωνα επισήμανσης παραμένουν στη θέση τους.
Το HTML ανανεώνει το query του viewer ώστε να φορτώνεται η διόρθωση.

Η λειτουργία «Σύμβολα CHₙ», οι συνεπτυγμένοι και ανεπτυγμένοι τύποι
συνεχίζουν να εμφανίζουν τα σύμβολα. Τα αρχικά MOL/SDF και όλα τα core
παρέμειναν αμετάβλητα για αυτή τη διόρθωση. Η εξαγωγή PNG χρησιμοποιεί
το διορθωμένο SVG και περιλαμβάνει την ίδια εμφάνιση.

## Έλεγχοι που ολοκληρώθηκαν

- JavaScriptCore έλεγχος σύνταξης viewer και `git diff --check`.
- Firefox και στα 4 αλκίνια × 2 τρόπους κύριας αλυσίδας: χωρίς C/πλαίσια,
  ακριβώς ίδιες συντεταγμένες όλων των γραμμών με το αρχικό SVG του JSME.
- Επισημάνσεις αλυσίδας, τριπλού δεσμού και μεθυλομάδας, σωστή αρίθμηση.
- Πραγματικά κλικ CHₙ και τύπων: επαναφορά συμβόλων και νέα αφαίρεσή τους.
- Επανασχεδίαση με επαναφορά κλίμακας και εξαγωγή PNG και των τεσσάρων.
- Επιλεγμένα αλκένια, αλκοόλη, νιτρίλιο και ενίνιο: γραμμές/ετικέτες
  ακριβώς ίδιες με απενεργοποιημένη τη νέα συνάρτηση.
- Χωρίς σφάλματα JavaScript. Screenshots και πραγματικό εξαγόμενο PNG
  επιθεωρήθηκαν οπτικά και αποθηκεύτηκαν στο `design/assets/`.

# Κενό γύρω από C σε κατακόρυφους δεσμούς αλκανίων — 30/10/2026

Εφαρμόστηκε το εγκεκριμένο πλάνο για τους κατακόρυφους C–C των διακλαδώσεων
στους ανεπτυγμένους τύπους. Τα native λευκά masks έφθαναν μέσα στα πραγματικά
όρια του χαρακτήρα C. Δεν χρειάστηκε μετακίνηση ατόμων ή αλλαγή μήκους δεσμού.

## Υλοποίηση

Το `js/mulermoc-nom-molview-52.js` προσθέτει το στενά περιορισμένο
`fPadExpandedAlkaneBranchLabels`, μετά το υπάρχον fit. Χρησιμοποιεί την
υπάρχουσα ταξινόμηση `seriesKey === 'alkanes'`, μόνο σε Expanded και μόνο
στα C των άκρων κατακόρυφων απλών C–C. Υπολογίζει τα πραγματικά bounds του
χαρακτήρα στις τοπικές SVG συντεταγμένες και αλλάζει μόνο y/height των
υπαρχόντων λευκών masks, με περιθώριο 0,06 του font size. Τα x/width των
masks, όλα τα κείμενα/γραμμές/θέσεις και ο μηχανισμός καρβοξυλίων παραμένουν ίδια.
Το περιθώριο υπολογίζεται ξανά σε rebuild/fit, χωρίς συσσώρευση μετασχηματισμών.

Η `mulermoc-nom-52.html` ανανεώνει μόνο το cache URL του viewer. Δεν άλλαξαν
core, MOL/embedded data, 3D, ονόματα, άλλα modes/κατηγορίες, σενάρια ή αρχεία
React. Το πείραμα C–H50% και η ήδη τεκμηριωμένη αυτόματη κλιμάκωση διατηρούνται.
Δεν υλοποιήθηκε νέος χημικός ή εκπαιδευτικός κανόνας· Chemistry Validator και
Learning Designer δεν απαιτήθηκαν για αυτή την καθαρά γραφική παρέμβαση.

## Έλεγχοι Developer

- Στατικό scope: μόνο το νέο helper, το fit hook και το cache URL. Το υπάρχον
  acid helper παραμένει byte-identical. Viewer JavaScript syntax και δύο Python
  AST checks PASS. 1.832 προϋπάρχοντα αρχεία εκτός στόχου παραμένουν ίδια,
  περιλαμβανομένων όλων των data/MOL/SDF/core/σεναρίων/React.
- Πραγματικός Firefox/JSME: 422 διαθέσιμες μορφές της βιβλιοθήκης πριν/μετά,
  στα 141 μόρια. Οι γραμμές, τα text markup και το viewBox είναι ίδια παντού.
  Πλήρες SVG byte-identical στις 419 ανεπηρέαστες μορφές. Αλλαγή masks μόνο
  στα Expanded των 2-μεθυλοπεντανίου, 2,3-διμεθυλοβουτανίου και
  3-αιθυλο-2,5-διμεθυλοεξανίου. Ίδια overlap/clipping πριν/μετά στα guards.
- Κενά από τα πραγματικά font bounds έως την ακμή του mask στα επηρεαζόμενα
  C: προηγουμένως περίπου −3,52 έως −1,18 px, μετά περίπου 0,87–1,32 px στην
  αρχική desktop σύγκριση. Η αρνητική τιμή σήμαινε ότι το mask τελείωνε μέσα
  στο bounding box του γράμματος, όχι ότι μετακινήθηκε το C.
- 36 περιπτώσεις parent/branch highlight × default/in/restored zoom × τρία
  μόρια × πλάτη1500/390 px: θετικό κενό περίπου 0,57–1,32 px, καμία επικάλυψη
  ή κομμένη ετικέτα. Τα390 px είναι responsive emulation, όχι φυσική συσκευή.
- PNG blob >1000 bytes και parseable SVG μετά τη διόρθωση. Δεν έγινε pixel
  σύγκριση PNG. Screenshots δύο επηρεαζόμενων μορίων επιθεωρήθηκαν οπτικά.
  Μηδέν JavaScript errors στην τελική εκτέλεση.

Η πρώτη δοκιμή σταμάτησε σε helper μέτρησης που αναζητούσε native masks και
σε compacted μορφές άλλων ενώσεων. Περιορίστηκε η μέτρηση κενών στο πραγματικό
scope· τα πλήρη SVG των άλλων μορφών συνέχισαν να συγκρίνονται. Πρόκειται για
διόρθωση του test harness, όχι του κώδικα της εφαρμογής.

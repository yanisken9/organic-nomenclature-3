# Namelecule React — δοκιμή 2D αιθανόλης, 26/10/2026

Εγκεκριμένο πεδίο: μία υπάρχουσα αιθανόλη (`ethanol`, C₂H₆O), τρεις μορφές 2D
και zoom στη δοκιμαστική React έκδοση. Κύρια έκδοση/δημοσιευμένοι σύνδεσμοι και
σταθερό branch `thesis-work` στο `3673c390` παραμένουν ως έχουν. Βάση εργασίας
`428254373936cfe3dfdbf03e879c654c25eb0747`, branch `react-library-pilot`.

## Υλοποιήθηκε

- Νέα διαδρομή `react-preview/dist/#/viewer`, `MoleculePreview` και χειριστήρια
  React με κατάσταση φόρτωσης/σφάλματος, επανάληψη και επιστροφή στην κύρια έκδοση.
- Παραγόμενο ίδιο-origin iframe από το αρχικό v51 HTML, με CSS μόνο για τη
  διάταξη και classic-script γέφυρα. Διατηρούνται DOM/αρχικοποίηση και η πλήρης
  υπάρχουσα διαδρομή MOL→JSME→SVG, μαζί με χρώματα/Η/συνεπτυγμένες ομάδες/font/fit.
  Η παραγόμενη αντιγραφή δεν φορτώνει Google analytics ή χειριστήρια σεναρίων.
- Μόνο εντολές μορφής/zoom, έλεγχοι origin/source/session/αύξοντος id, αγνόηση
  παλιών απαντήσεων και τερματικό σφάλμα μέχρι retry. Cleanup listeners/timers/
  iframe στο unmount. Προθεσμίες φόρτωσης 90s και απάντησης εντολής 10s.
- Διακριτές ονομασίες Κύρια έκδοση / Namelecule React — Δοκιμαστική έκδοση.
  Καμία νέα εξάρτηση ή αλλαγή ύλης, μορίου, σεναρίου ή παλιού renderer.

Πρόκειται για ενσωμάτωση χειριστηρίων, όχι μεταγραφή του renderer σε React.
Το ίδιο-origin iframe απομονώνει DOM/lifecycle, όχι πρόσβαση ασφαλείας.
Η αρχικοποίηση διατηρεί το JSmol/3D και τις υπάρχουσες δικτυακές εξαρτήσεις·
δεν επιλύει τα παλαιότερα σφάλματα `this.viewer is null`. Η αφαίρεση αυτών των
εξαρτήσεων απαιτεί ξεχωριστό μελλοντικό σχεδιασμό.

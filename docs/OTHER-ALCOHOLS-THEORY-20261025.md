# Θεωρία «Άλλες αλκοόλες» — 25/10/2026

Εγκεκριμένη προσθήκη 22 βημάτων στην υπάρχουσα δεύτερη υποενότητα αλκοολών.
Το μάθημα συνεχίζει τις κορεσμένες μονοσθενείς αλκοόλες με σταδιακή αποκάλυψη,
χωρίς κουίζ, βαθμολόγηση, ισομέρεια ή νέα λειτουργία. Δεν προβάλλεται ένας
κοινός γενικός μοριακός τύπος για τις διαφορετικές κατηγορίες.

| Βήματα | Περιεχόμενο και υπάρχοντα μόρια |
|---|---|
| 1–5 | 1,2-προπανοδιόλη, 1,2,3-προπανοτριόλη, 2-μεθυλο-1,2-προπανοδιόλη |
| 6–13 | 3-βουτεν-2-όλη, 4-πεντεν-2-όλη, 2-πεντεν-1-όλη, 3-μεθυλο-3-βουτεν-2-όλη |
| 14–15 | 3-μεθυλο-4-πεντιν-2-όλη |
| 16–20 | 4-μεθυλο-4-πεντεν-2-ιν-1-όλη, 3-αιθυλο-4-μεθυλο-3-εξεν-5-ιν-2-όλη |
| 21–22 | Σύνθεση σε 2D, προαιρετική παρατήρηση σε 3D, με επιλογή από τα δέκα μόρια |

Προηγείται η μεταβολή του αριθμού των OH και της κατάληξης και ακολουθούν
η προτεραιότητα OH στην αρίθμηση, οι θέσεις πολλαπλών δεσμών και οι διακλαδώσεις.
Τα μεγάλα παραδείγματα μοιράζονται σε περισσότερα βήματα. Οι κανόνες ανοίγουν
με επιλογή του μαθητή. Διατηρούνται η σχολική ελληνική γραφή και οι ρητές θέσεις.
Η παιδαγωγική σειρά σχεδιάστηκε με στοχευμένη πρόταση του Learning Designer·
δεν έχει πραγματοποιηθεί εμπειρική αξιολόγηση μαθησιακής αποτελεσματικότητας.

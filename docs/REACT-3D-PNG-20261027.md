## Implementation

`react-preview/src/MoleculePreview.jsx` offers PNG for the active2D/3D view and
sends a view/model/mode/symbols/naming/component/preferences snapshot. React
keeps the existing session/source/origin/latest-ACK/model validation. A3D export
has a100s parent budget, retained by later queued commands until the latest ACK;
2D and ordinary commands retain their10s parent timeout. The UI reports a
requested download, not proof that a user saved it to disk.

`react-preview/public/viewer-host-bridge.js` keeps the ordered native queue and
validates the snapshot. 3D calls unchanged `fSaveJmolPng`, including its native
Save Image prompt, user-chosen filename, footer, current visual settings and
1200×1200 image bytes. A scoped prompt observer delegates the real dialog and
notes null cancellation; it restores the original function after completion,
failure or pagehide. Native JSmol's local-save hook observes the final filename
and then returns to its original encoding/download path. An actual data-URL PNG
anchor, including signature checking when its MIME label follows a renamed
extension, establishes the requested status. No image is generated by React.

The queue waits for native write/script completion and its delayed echo cleanup
before applying later model/view/component commands. Native cancellation can
discard the queued marker: after cleanup a fresh synchronization marker returns
a nonfatal failed-download status. 3D prompt/encoding has a90s fail-closed bound;
late saves after failure/unmount are blocked. Existing2D blob download behavior
and8s bound are retained. Generated viewer host/dist and ReactREADME complete
runtime/documentation changes; no host-generator or package changes.

## Diagnostic history and limits

Native Save Image prompts were initially auto-dismissed by default WebDriver
behavior. The harness now accepts the actual defaultValue explicitly, or supplies
the chosen name/dismissal for the case. An early adapter treated empty input as
cancellation; that assumption was removed, preserving native filename semantics.
An actual cancel exposed discarded Jmol marker behavior, fixed in the adapter.
A queued command initially reset a long export's parent timer to10s; it now
retains the export budget and has a greater-than10s regression case.

An initial lifecycle harness used the9237 readiness profile while observing the
9238 download folder. Concurrent9238 files made those assertions invalid; a prior
90.17s deadline was observed but is not reported as a final passing run. Final
download suites both use9238 sequentially. The file filter also had to include
native user-selected names without extensions. Overly strict3D byte equality
and then16/255 shading bounds were rejected after observing native shading
variation, with unchanged scenes/cameras and visual inspection of the images.
These are distinct harness issues and adapter findings, not successful checks.

The known intermittent external JSmol setDisplay/null-viewer issue remains;
raw errors are retained and only that exact known CDN signature is classified
separately by tests. No production error suppression or lifecycle-library fix.
Existing mobile camera/framing limitations are preserved, not corrected by this
export change. No Safari/touch/AT/offline/Drupal or all126molecule export combinations. No new
chemistry, learning-content, conformer or full React-code-rewrite certification.
The80–85% functional-use estimate discussed with the user is unmeasured, not a
formal migration-completion metric; existing chemistry/renderers can remain in
an otherwise complete React interface.

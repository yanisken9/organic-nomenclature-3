# Αύξηση κοινής 2D κλίμακας κατά 15% — 26/10/2026

Εγκεκριμένη δοκιμή: όλα τα μόρια και οι τρεις μορφές προβάλλονται 15%
μεγαλύτερα, διατηρώντας το κοινό μέγεθος χαρακτήρων στο ίδιο πλαίσιο/zoom.

Αλλαγή μόνο στον viewer51 και στην παράμετρο cache του HTML51:
πολλαπλασιαστής 1,15 στην κοινή κλίμακα. Για να μη σμικρύνονται αυτόματα
τα μεγαλύτερα μόρια, το περιθώριο αρίθμησης μειώθηκε από 650 σε 350
εσωτερικές μονάδες και το αναλογικό περιθώριο από 6% σε 4%.
Η ασφαλής προσαρμογή μεγαλύτερων ελεύθερων δομών διατηρείται.

## Πραγματικοί έλεγχοι

- Firefox: **942 περιπτώσεις**, 314 διαθέσιμες μορφές/105 μόρια × τρία
  πλάτη παραθύρου 1500/900/390. Ίδιο εμφανιζόμενο font size, χωρίς αποκοπές
  γραμμάτων ή αριθμήσεων. Μηδέν σφάλματα JavaScript.
- Μετρήθηκαν 13,538 CSSpx αντί 11,772 στα πλατύτερα πλαίσια και 10,450
  αντί 9,087 στο στενό. Σύγκριση με τα προηγούμενα πραγματικά αποτελέσματα
  επιβεβαιώνει λόγο 1,15 για όλα τα μετρημένα σύμβολα, όχι μόνο τον στόχο.
- Η αρίθμηση ελέγχθηκε σε κάθε διαθέσιμη μορφή. Τα 3D echoes απενεργοποιούνται
  προσωρινά μόνο μέσα στο test της σάρωσης, ώστε να απομονώνεται το 2D.
- Πραγματικά κουμπιά των τριών μορφών, zoom ×1,25/επιστροφή και PNG/έγκυρο
  standalone SVG export PASS. Ελέγχθηκαν εικόνες του μεγαλύτερου μορίου,
  μαζί με την αρίθμηση, και του αιθυλοϊσοπροπυλαιθέρα.
- Στον αρχικό έλεγχο προστασίας 973 από τα 975 αρχεία ήταν πανομοιότυπα·
  οι μόνες αλλαγές εφαρμογής είναι viewer51/HTML51. Τα αρχεία σημειώσεων και
  αναφορών ενημερώθηκαν στη συνέχεια. Δεν επαναλήφθηκαν χημικές δοκιμές για
  μοριακά αρχεία που διατηρήθηκαν ακριβώς ίδια.

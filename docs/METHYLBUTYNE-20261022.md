# 3-μεθυλο-1-βουτίνιο — τοπική προσθήκη, 22/10/2026

Ο χρήστης επιβεβαίωσε το **3-μεθυλο-1-βουτίνιο**, HC≡C–CH(CH₃)–CH₃,
με την ίδια διαδικασία/εμφάνιση όπως τα προηγούμενα μόρια. Δεν προστέθηκε
η αρχική μη έγκυρη ονομασία 2-μεθυλο-1-βουτίνιο.

Κλειδί `methyl_3_butyne_1`, τύπος C₅H₈, κατηγορία Αλκίνια. Σύνολο 76 μόρια
τοπικά· η τελευταία δημοσιευμένη έκδοση έχει 73, στο `41c3852`.

## Σχέδια και δεδομένα

- Τρία νέα MOL στο `mols/new_molecules/methyl_3_butyne_1_2D_*.mol`,
  προγραμματιστικά σχέδια που ακολουθούν το αντίστοιχο διακλαδισμένο αλκένιο.
  Δεν είναι εξαγωγές KingDraw.
- Συνεπτυγμένος/ανεπτυγμένος: τέσσερις C οριζόντια, τριπλός δεσμός δεξιά,
  μεθυλομάδα κάτω από τον C2 του αρχείου (θέση 3 στην ονομασία).
  Διαστήματα C–C 1,17 και C–H 0,78, όπως στο προηγούμενο πρότυπο.
- Ανέπτυγμένος: 5 C και 8 ρητά H. Τερματικός sp άνθρακας με ένα Η,
  εσωτερικός sp άνθρακας χωρίς Η, διακλαδισμένος CH με ένα Η.
- Σκελετικός: διατηρήθηκε η διάταξη της διακλάδωσης· οι C2–C3–C4 του αρχείου
  είναι συνευθειακοί γύρω από τον τριπλό δεσμό.
- Stored αλυσίδα 2D `[4,3,2,1]`. Ισοδύναμη εναλλακτική `[4,3,2,5]`.
- Αυτούσιο SDF **PubChem CID69019**, runtime στο `mols/nomeclature-moc2/`
  και πηγή στο `mols/new_molecules/`. Stored αλυσίδα 3D `[5,4,1,2]`.
  Πηγή: https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/3-methyl-1-butyne/SDF?record_type=3d
- Η εγγραφή μπήκε τελευταία στο data49, διατηρώντας τους 75 προηγούμενους
  δείκτες των παραδειγμάτων. Προστέθηκαν MOL embeds/registry και query cache
  στο HTML. Κανένα core δεν τροποποιήθηκε.

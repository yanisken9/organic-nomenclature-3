# Μικρή αύξηση γραμμάτων ονομασίας — 28/10/2026

Ο χρήστης ενέκρινε μικρή αύξηση, περίπου 10–15%, με το όνομα σε μία γραμμή,
μειώνοντας λίγο τα εσωτερικά περιθώρια. Δεν εγκρίθηκε η προηγούμενη πρόταση
για ελάχιστο μέγεθος 16px/αναδίπλωση ή η ξεχωριστή διόρθωση του HCOOH.

Η κύρια έκδοση ενεργοποιεί `data-namelecule-compact-name-padding="true"`.
Ο viewer μετρά πρώτα με τα συνηθισμένα περιθώρια. Αν το όνομα δεν χωράει,
εφαρμόζει οριζόντια περιθώρια 4.5px αντί 6px στα boxed συνθετικά, πριν από
την υπάρχουσα προσαρμογή της γραμματοσειράς. Κάθε νέα μέτρηση επαναφέρει
αρχικά την κανονική απόσταση. Τα σύντομα ονόματα και τα unboxed συνθετικά
κρατούν την προηγούμενη εμφάνιση. IDs, σειρά, επιλογή και μηχανισμός σεναρίου
διατηρούνται. Hosts χωρίς την ενεργοποίηση κρατούν την παλιά προσαρμογή.

Runtime αρχεία: `css/namelecule-52.css`, `js/mulermoc-nom-molview-52.js`,
`mulermoc-nom-52.html` (ενεργοποίηση και ανανέωση cache URLs).
Δεν αλλάζουν core52, MOL/SDF, σενάρια JSON ή React αρχεία.

Η ευρύτερη προϋπάρχουσα δυσκολία αναγνωσιμότητας εξαιρετικά μεγάλων ονομάτων
σε στενό χώρο δεν εξαλείφεται με αυτή τη μικρή ρύθμιση. Ο χρήστης επέλεξε
δοκιμαστικά τη μικρή αλλαγή αντί αναδίπλωσης. Το σκοτεινό rectangle HCOOH
του νέου μαθήματος παραμένει ξεχωριστή εκκρεμότητα.

Τα αρχεία `name-font-before*` καταγράφουν την πραγματική αφετηρία της αλλαγής,
επειδή μεγάλο μέρος της κύριας v52 είναι ακόμη untracked έναντι HEAD
`168e3cec01f941a84d40bbe0dc07156e7baa35d0`. Τα υπόλοιπα Git changes προϋπήρχαν.
Έλεγχοι και τελικό ανεξάρτητο review καταγράφονται στις τρέχουσες σημειώσεις.
Τοπική αλλαγή, χωρίς commit, push ή δημοσίευση.

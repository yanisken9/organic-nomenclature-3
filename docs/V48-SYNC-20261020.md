# Συγχρονισμός της ενημερωμένης v48 — 2026-10-20

## Βάση και μέθοδος

Με έγκριση του Γιάννη συγχρονίστηκε τοπικά η v48 με upstream commit
`f1ac038` του καθηγητή. Προηγούμενη upstream βάση `aeb6bf0`· προσωπικό HEAD
πριν από τον συγχρονισμό `b9f3949`. Χωριστό clone για σύγκριση:
`/tmp/namelecule-v48-sync-review-20261020`. Δεν έγινε commit/push/δημοσίευση.

Χρησιμοποιήθηκε τριμερής συνδυασμός (προηγούμενο upstream, δική μας έκδοση,
νέο upstream) για HTML, δύο base CSS, core/molview/teaching/scenario και
ui-icons. Δεν προέκυψαν text conflicts· αυτό μόνο του δεν αποτελεί λειτουργικό
έλεγχο. Το data_48.js πήρε τη νέα upstream βάση με τις δικές μας δύο εγγραφές
metadata (formula και stored chains). Παραμένουν 71 μοναδικά κλειδιά.

## Αλλαγές που μεταφέρθηκαν

- Προτεραιότητα πολλαπλών δεσμών στην κύρια αλυσίδα. Το μεθυλοπροπένιο
  έχει πλέον 2 υποψήφιες αλυσίδες που περιέχουν C=C (αντί 3 με μία κορεσμένη).
- Νέα ρύθμιση συνολικού ύψους δύο viewers, αποθήκευση ανά βήμα,
  αποκατάσταση γύρω από παρουσίαση, κοινό ελάχιστο ύψος και υπολογισμός
  χώρου του κειμένου βήματος. Οι τρέχουσες τιμές ακολουθούν τον κώδικα
  upstream (VIEWER_MIN_H=150, combined height 300–1000), όχι παλιότερη
  ενδιάμεση τιμή 240 που περιγράφεται επίσης στο ιστορικό changelog.
- Αλλαγές σε εμφάνιση/κίνηση pinned authoring, εικονίδια και modal
  επιβεβαίωσης διαγραφής, σύνδεση save-image controls με per-step ρυθμίσεις.

## Τοπικές προσαρμογές που διατηρήθηκαν

Namelecule header/logo/welcome και ξεχωριστό theme, mint highlights και teal
αριθμοί, κοινή fFit2DSVG, showStepNumbers/reserveTitleSpace σε όλο τον κύκλο
σεναρίων, σωστός τίτλος κάτω από playbar. Διατηρείται η διορθωμένη ονομασία
3-μεθυλο-1-βουτένιο (core comp1No), όπως και τα stored chains των δύο μορίων.

Και οι 71 εγγραφές MOL2D upstream είναι ίδιες με τις δικές μας. Ειδικά τα
KingDraw σχέδια δεν αντικαταστάθηκαν από διαφορετικές γεωμετρίες. Τα δύο
PubChem SDF έχουν ίδια atom/bond records· διαφέρει μόνο το timestamp του
header. Κρατήθηκαν τα ήδη τεκμηριωμένα τοπικά SDF. Η δική μας σελίδα υποδοχής,
τα σενάρια και ο φάκελος Desktop JSON δεν άλλαξαν.

## [v55] (tiered 3D for drafts; LIVE, `index.html` → v55)

Forked from v54 (`mulermoc-nom-55.html` + `js/*-55.js` + `css/*-55.css`, `?v=55.0`). Draft 3D is now 3-tier: PubChem SDF → JSmol remote `load $SMILES` (`fMolDraftRemote3DFromJSmol`: applet proxy-routed, works CDN + local, no page-side fetch so no CORS wall; scriptWait + SDF read-back, validated) → local 2D-MOL + UFF minimize in JSmol (offline, `fMolDraftLocal3DFromMol`: inline `load data` + `add hydrogens` + blocking `minimize steps 500` via scriptWait — fire-and-forget raced read-back with pre-minimize coords — then SDF extracted back via `molFile`/`show MOL`, validated by `fMolDraftValidSDF3D` heavy-count + non-flat-z). Orchestrated by `fMolDraftFetchSDF3DTiered` with epoch/submitId guards; preview shows source-labeled 3D row (local flagged provisional), fetching note, all-miss 2D-only note. Accept ungated on any tier success (was PubChem-3D-only); provenance persisted as `sdf3DSource` (rec + update path + history + save-file headers). SDF read-back is `write MOL` alone (translate-test proved it the sole live-model serializer: `molFile` returns an unparseable layout, `fileContents` is a stale dump), logging length + heavy count + heavy-only z-spread + verdict. The V2000 parser now reads z (flat-2D text correctly fails the non-flat check, spread over heavies only so H-noise can't fake 3D). The planar-saddle trap (exactly-flat input freezes MMFF: zero heavy displacement) plus E=46000+ overlap divergence are broken by a pure-JS 2D untangle (spreads non-bonded heavy overlaps) + z-jiggle (±0.3 Å), both self-verifying, with tier-3 acceptance requiring heavy displacement vs the prepared input (`fMolDraftMovedEnough`, mean ≥ 0.05 Å) plus plain-`minimize` retry; `zap`-first loads with `calculate hydrogens`, live load-verify (heavy count + matches-loaded ≈ 0), always-show-flat-3D on total miss, and a manual Minimize-3D fallback button in the preview: pressing it runs the pipeline, then an OK-only dialog asks to save the 3D conformation once optimization completes — OK stores best-effort (`jsmol-min` when validated, `jsmol-unminimized` live model otherwise) and unlocks Accept (ESC/backdrop = back out, stay locked). Minimize is fire-and-forget (follow-up scripts interrupt the in-flight run — console-proven) with a single delayed read-back, explicit MMFF-then-UFF force fields, and iterative re-minimize from the live model on repeat presses (movement judged vs the pre-fire snapshot, no convergence requirement — partial descent counts). `?v=55.0` unchanged across all v55 commits — hard-reload (Ctrl+Shift+R) after pulling.

# Ομοιογένεια ανεπτυγμένων αιθέρων — 31/10/2026

Εγκεκριμένη προσαρμογή και των **11 αιθέρων**: C–H **0,3094**, C–C/C–O
**0,6188**, σε σχεδιαστικές μονάδες MOL, όχι φυσικά μήκη δεσμών.

## Αλλαγές και επαναφορά

Τα τέσσερα παλαιότερα ενσωματωμένα MOL συμφωνούσαν byte προς byte με data50
του καθηγητή στην ελεγμένη upstream αναθεώρηση `4e1190ab`. Οι επτά νεότερες
προσθήκες διατηρούν την εγκεκριμένη οριζόντια διάταξη των αλκυλίων.

Αλλάζουν μόνο x/y των 11 embedded ανεπτυγμένων και των εννέα υπαρχόντων
αρχείων πηγής. Διμεθυλαιθέρας και αιθυλομεθυλαιθέρας είναι μόνο ενσωματωμένοι.
Αριθμοί/στοιχεία ατόμων, δεσμοί, z, τίτλοι και λοιπά πεδία διατηρούνται.
Διατηρούνται οι μικρές αρχικές κλίσεις του ισοπροπυλομεθυλαιθέρα και οι
υπάρχουσες συμβάσεις τελικής αλλαγής γραμμής των MOL.

Ο viewer52 επεκτείνει την υπάρχουσα ρύθμιση χαρακτήρων/αρίθμησης στους 11
γνωστούς αιθέρες, με βαθμονόμηση και από C–O για τον διμεθυλαιθέρα που δεν
έχει C–C. Η ρύθμιση δεν μετακινεί άτομα. Το HTML52 αλλάζει δύο παραμέτρους
cache. Οι άλλες μορφές, core, 3D, React και JSON θεωρίας διατηρούνται.

Ακριβείς διαδρομές/hashes στο `checks/ether-uniform-20261031/baseline.json`,
αρχικές πηγές στο `before-sources.json.gz`, διαφορά στο `approved-source.diff`.
Η γεννήτρια `transform.py --apply` αρνείται απροσδόκητη αλλαγή των πηγών.
Για επαναφορά συγκρίνουμε πρώτα τα τρέχοντα hashes με το τελικό target.
Πλήρες προηγούμενο checkpoint: `03c2d138504abad3884e707ee7ae9bd6aa5d39da`.

## Όρια

Η αρχική αυστηρή σύγκριση raw SVG/viewBox σταμάτησε σε συνεπτυγμένο
διμεθυλαιθέρα: εσωτερική κατακόρυφη μετατόπιση περίπου 0,06667 μονάδων
viewBox και διαφορά μίας μονάδας σε native κείμενα/πλαίσια, ενώ οι πραγματικές
CSS θέσεις/γραμματοσειρές των γραμμάτων έμειναν ίδιες. Τα αρχικά αποτυχημένα
κριτήρια/σύγκριση διατηρούνται. Η τελική δοκιμή μετρά ρητά ορατές θέσεις
(μετρημένη μέγιστη απόκλιση 0 CSS px) και raster επαφών γραμμάτων–δεσμών,
κρυμμένων γραμμών και αποκοπής. Δεν δηλώνεται διορθωμένη αρχική αιτία ούτε
κλειστή η παλαιότερη διερεύνηση αστάθειας του κάδρου.

Τα πλάτη είναι προσομοίωση σε headless Firefox, όχι πιστοποίηση φυσικού
κινητού ή Safari. Παραμένουν εξωτερικές εξαρτήσεις JSmol/j2s. Δεν αποτελεί
τελική πρόβα ή offline πακέτο συνεδρίου.

Η αλλαγή είναι **τοπική**, χωρίς νέο commit/push/δημοσίευση. Η δημόσια αναφορά
καθηγητή παραμένει η έκδοση πριν από αυτή την ενότητα.
**Δεν άλλαξε κανένα αρχείο core σε αυτή την ενότητα.**

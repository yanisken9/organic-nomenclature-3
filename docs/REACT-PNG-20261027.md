# React — 2D PNG export, 27/10/2026

Approved scope: add a React control invoking the existing main52 fSave2DPng,
keeping the main application unchanged. No new renderer/chemistry/molecules,
3D export, dependency, commit, push or publication.

Three runtime sources change: src/MoleculePreview.jsx, public/viewer-host-bridge.js
and src/preview.css. The native exporter, SVG/MOL pipeline and name-box drawing
are reused unchanged. There is no second serializer or drawing implementation.

The command binds molecule, normalized 2D mode, CHn, naming preference and selected
component. Both ends preserve origin/source/session/request/model gates; the
source rechecks the export context. The control waits for the latest ACK and is
disabled while loading or in3D. Existing sequential numbering finishes before
snapshot. A newer command cancels export before its snapshot. After invocation,
the queue stays held through the native asynchronous callback, preserving globals
used by its filename. A capture-phase listener observes the native blob-anchor
click and ACKs a download request, not a completed disk save. No default download
is replaced or redirected by production code.

Synchronous native errors return an export failure without killing the viewer.
An8s native asynchronous timeout stops the host, prevents a late anchor download,
and presents an export-specific retry. Retry unloads native callbacks; this avoids
resuming a queue whose old callback might still use changed globals. An exported
file's final location/save decision is handled by the user's browser.

## Existing limitations and scope

The existing native fDrawNameBoxes uses a fixed40px footer font and width1200.
Very long names are visibly cropped at both edges. The complex ketone exhibits
this in both React and standalone main PNGs with identical bytes. This is a
pre-existing exporter limitation, not a new PNG regression or a claim of complete
name readability for large compounds. It was reported to the user and deliberately
not fixed by changing main code or inventing another drawing method.

The user's normal browser settings are untouched. The actual OS Save dialog,
Safari/AT/Drupal/all126molecules/all283lesson steps were not tested. PNG export
requests do not certify disk persistence or the user's final save choice. The
existing renderer/engine remains in a same-origin iframe, not a security sandbox.
No new IUPAC/conformer or complete React-migration certification is claimed.

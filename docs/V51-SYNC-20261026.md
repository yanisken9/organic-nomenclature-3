## Περιεχόμενο και διατήρηση

Προστέθηκαν παράλληλα HTML51, έξι JS51, τρία CSS51 και οι upstream vendored
jQuery 4/DOMPurify με τις άδειες/τεκμηρίωσή τους. Το `js/ui-icons.js` ενημερώθηκε.
Η υποδοχή και οι επτά σύνδεσμοι της βιβλιοθήκης οδηγούν στη v51. Το index
παραμένει στην υποδοχή Namelecule. Η προηγούμενη v50 παραμένει διαθέσιμη και
τα δικά της αρχεία δεν αλλάζουν σε αυτή την εργασία.

- Ο νέος core51 είναι αυτούσιο upstream αρχείο. Οι υπάρχουσες διορθώσεις
  κλάδων, αρίθμησης/οριζόντιας ισοδύναμης αλυσίδας και αλκοολών έχουν ήδη
  ενσωματωθεί από τον καθηγητή. Δεν προστέθηκε νέος τοπικός αλγόριθμος χημείας.
- Διατηρήθηκε ο native SVG renderer `MuSVG`, μαζί με το upstream parser fix
  `text/html`/`adoptNode`. Δεν φορτώνεται Snap.svg στη v51.
- Με τριμερή συγχώνευση μεταφέρθηκαν οι τοπικές προσαρμογές fitting 2D,
  διαστήματος ετικετών, ονομάτων, μεγεθύνσεων 3D, κανόνων/αρίθμησης και OH.
  Η παλιά function διόρθωσης διπλών δεσμών δεν επανήλθε.
- Η νέα υποστήριξη σημειώσεων HTML/DOMPurify και ο μεγάλος επεξεργαστής
  συνδυάστηκαν με φόρτωση μαθήματος, επιστροφή στη βιβλιοθήκη, τίτλους,
  ρυθμίσεις viewer και αρχικά κλειστούς κανόνες Namelecule.
- Data51: ίδια 98 μόρια, σειρά, MOL, μεταδεδομένα, αντιστοιχίσεις και κάμερες
  με την τοπική v50. Δεν αντικαταστάθηκαν από τη διαφορετική upstream διάταξη.
- Όλα τα παλιά MOL/SDF/provenance και τα επτά JSON μαθημάτων έμειναν αυτούσια.
  Το πεδίο app των παλιών JSON παραμένει ως έχει και γίνεται δεκτό από τη v51.
  Δεν χρειάζεται ανανέωση των Desktop JSON για αλλαγή έκδοσης εφαρμογής.
- Δεν αντικαταστάθηκαν τα τέσσερα κοινά SDF που διαφέρουν από το upstream.
  Διατηρήθηκαν τα ελεγμένα τοπικά αρχεία και τα hashes προέλευσης PubChem/RDKit,
  αποφεύγοντας γενική αλλαγή της 3D στερεοχημικής αποθήκευσης.
- Η προεπιλογή JSmol είναι CDN. Η upstream επιλογή `?libs=local` διατηρείται,
  αλλά απαιτεί ξεχωριστά τα μη αποθηκευμένα στο Git JSmol/j2s αρχεία. Δεν
  εγκαταστάθηκε/πιστοποιήθηκε πλήρης offline λειτουργία.

Δεν αντικαταστάθηκαν τα τοπικά ιστορικά σχέδια/σημειώσεις με upstream έγγραφα.
Το τρέχον upstream CHANGELOG ελέγχθηκε μέσω δικτύου και καταγράφηκε στις

### Αρχικές αστοχίες και όρια

Η αρχική εγκατάσταση αναζήτησε SVG πηγής εικονιδίου που δεν υπάρχει στο Git·
το ίδιο εικονίδιο είναι ήδη ενσωματωμένο στο upstream ui-icons, άρα δεν χρειαζόταν
ξεχωριστό αρχείο. Ο αρχικός regex έλεγχος assets μπέρδεψε το δυναμικό
`document.write` του upstream με διαδρομή· αντικαταστάθηκε με HTMLParser.
Ο πρώτος έλεγχος μαθημάτων ολοκλήρωσε 153 βήματα αλλά σταμάτησε σε λανθασμένη
υπόθεση του test ότι ο πίνακας κανόνων είναι HTML table. Διορθώθηκε σε έλεγχο
των πραγματικών div rows και η πλήρης σουίτα επαναλήφθηκε επιτυχώς.

Ο πολύ πρώιμος τεχνητός χειρισμός authoring πρόλαβε το ασύγχρονο default preload,
που αντικατέστησε το νέο προσωρινό περιεχόμενο. Αυτή η διαδρομή boot προϋπήρχε·
το test περιμένει πλέον την ολοκλήρωσή της. Δεν προστέθηκε νέο κλείδωμα UI και
δεν δηλώνεται ότι εξαλείφθηκε κάθε race στην αρχικοποίηση του authoring.
Οι ολοκληρωμένες λειτουργικές δοκιμές δεν αναιρούν αυτές τις καταγραφές.

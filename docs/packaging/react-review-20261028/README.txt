NAMELECULE — ΔΟΚΙΜΑΣΤΙΚΗ REACT ΓΙΑ ΑΞΙΟΛΟΓΗΣΗ
Πακέτο 28/10/2026

1. Αποσυμπιέστε ΟΛΟ το ZIP. Διατηρήστε τη δομή φακέλων.
2. Ανοίξτε τερματικό μέσα στον φάκελο Namelecule-React-Review-2026-10-28.
3. Με εγκατεστημένη Python 3 εκτελέστε

   macOS / Linux
   python3 serve.py

   Windows
   py -3 serve.py

   Αν η εντολή Python ονομάζεται python στο σύστημά σας
   python serve.py

4. Ανοίγει η υποδοχή της React στον προεπιλεγμένο browser. Αν δεν ανοίξει,
   αντιγράψτε τη διεύθυνση REACT που τυπώνεται στο τερματικό.
5. Κρατήστε το τερματικό ανοιχτό όσο δοκιμάζετε. Για τερματισμό πατήστε Ctrl+C.

Δεν απαιτούνται Node/npm, εγκατάσταση εξαρτήσεων ή νέο build για αυτή τη δοκιμή.
Μην ανοίγετε το dist/index.html με διπλό κλικ/file://. Μην σερβίρετε μόνο το dist.
Το script επιλέγει ελεύθερη θύρα και ακούει μόνο στο127.0.0.1, όχι στο δίκτυο.
Εκτυπώνει και σύνδεσμο MAIN WELCOME για την κύρια έκδοση μέσα στο ίδιο πακέτο.
Για χειροκίνητη εκκίνηση χωρίς αυτόματο άνοιγμα browser
python3 serve.py --no-browser

ΤΙ ΠΕΡΙΛΑΜΒΑΝΕΙ

Το υπάρχον React build και τα πηγαία αρχεία/lockfile για μελέτη, μαζί με τα κοινά
αρχεία JSME, JS/CSS, μοριακές πηγές/SDF, σενάρια, εικόνες και σελίδες υποδοχής
που απαιτούνται από τους hosts και τις διαδρομές επιστροφής. Περιλαμβάνονται
οι υπάρχουσες άδειες/THIRD-PARTY-NOTICES όπου παρέχονται με τα επιλεγμένα αρχεία.
Δεν περιλαμβάνονται .git, node_modules, credentials, τοπικές ρυθμίσεις agents,
παλαιά ZIP/backup ή προσωπικά αρχεία.

ΣΤΙΓΜΙΟΤΥΠΟ ΚΑΙ ΟΡΙΑ

Η δοκιμαστική React έχει κατάλογο126μορίων,377διαθέσιμεςμορφές2D και12μαθήματα
με283βήματα. Η React διαχειρίζεται τη διεπαφή, αλλά η απεικόνιση/ονοματολογία
παραμένει στον υπάρχοντα κινητήραv52 μέσω same-origin iframe/JSME/JSmol.
Δεν είναι ανεξάρτητος χημικός κινητήρας ούτε πλήρης μετάβαση όλων των λειτουργιών.

Τα κοινά runtime αρχεία/η κύρια έκδοση είναι το τρέχον τοπικό στιγμιότυποv52
με136μόρια,21οξέα και14μαθήματα/337βήματα. Το React metadata/build παραμένει
στα126/12· δεν έγινε rebuild ή συγχρονισμός των πρόσφατων οξέων/μαθημάτων.
Δεν εγγυάται ότι ένα νέο npm build θα αναπαράγει αυτό το στιγμιότυπο με τον
νεότερο κατάλογο της κύριας. Για την αξιολόγηση χρησιμοποιήστε το έτοιμο dist.

Χρειάζεται σύνδεση στο διαδίκτυο για τις υπάρχουσες βιβλιοθήκες JSmol/CDN.
Αυτό ΔΕΝ είναι πλήρες offline πακέτο. Η προαιρετική ρύθμιση libs=local δεν
υποστηρίζεται από το συγκεκριμένο ZIP, που διατηρεί την κανονική διαδρομήCDN.

Παραμένουν καταγεγραμμένοι περιορισμοί JSmol lifecycle κατά το teardown iframe,
μεγάλων ονομάτων/PNG και το γνωστό P2 σκοτεινό rectangle του συνεπτυγμένου HCOOH.
Δεν δηλώνεται καθολική χημική/οπτική/διαφυλλομετρική πιστοποίηση.

ΕΛΕΓΧΟΣ ΑΚΕΡΑΙΟΤΗΤΑΣ

Το PACKAGE-MANIFEST.json περιέχει SHA256 ανά αρχείο του πακέτου, εξαιρώντας
μόνο τον ίδιο τον manifest. Το συνοδευτικό .sha256 αφορά ολόκληρο το ZIP.
Το πακέτο προορίζεται για ιδιωτική αξιολόγηση/συνεργασία, όχι ως νέα δημοσίευση.

# Πείραμα C–H ανεπτυγμένων αλκανίων — 30/10/2026

Ο χρήστης ενέκρινε μείωση κατά 50% σε όλα τα οκτώ αλκάνια, περιλαμβανομένων
των προϋπαρχόντων. Αποθηκεύτηκε πλήρες baseline αμέσως μετά την εναρμόνιση
των δύο δικών μας αλκανίων, ώστε η δοκιμή να μπορεί να αναστραφεί.

## Αλλαγή δεδομένων

Για κάθε ρητό Η εφαρμόστηκε `H′ = C + 0.5 × (H − C)`, από τον πραγματικό
συνδεδεμένο C του ίδιου MOL. Οι C, z, indexed atoms/bonds, κατευθύνσεις,
κεφαλίδες, metadata και όλα τα μη γεωμετρικά πεδία διατηρήθηκαν.
Το V2000 κρατά τέσσερα δεκαδικά· μέγιστο σφάλμα στρογγυλοποίησης ανά
συντεταγμένη 0,00005 μονάδες MOL.

Επηρεάζονται 90 H σε οκτώ ενεργά Expanded records: μεθάνιο, αιθάνιο,
προπάνιο, βουτάνιο, πεντάνιο, 2-μεθυλοπεντάνιο, 2,3-διμεθυλοβουτάνιο,
3-αιθυλο-2,5-διμεθυλοεξάνιο. Ενημερώθηκαν τα οκτώ embedded records στο data52
και τα τρία υπάρχοντα εξωτερικά Expanded MOL αντίγραφα. Δεν προστέθηκαν
διαφορετικού τύπου εγγραφές ή νέα runtime functions.

Δεν άλλαξαν αποθηκευμένοι C–C, συνεπτυγμένοι/σκελετικοί, 3D, core, viewer,
πολιτική γραμματοσειρών, JSON σεναρίων ή React. Το baseline και ο generator
αποτρέπουν επαναληπτικό υποδιπλασιασμό σε επανεκτέλεση.

## Πραγματικό αποτέλεσμα στην οθόνη

Η μείωση **των συντεταγμένων MOL** είναι 50%. Η εγγενής κανονικοποίηση του
JSME και το υπάρχον fit μεταβάλλουν την κλίμακα της εικόνας. Επομένως:

- Στο μεθάνιο η προβαλλόμενη απόσταση C–H έμεινε ουσιαστικά ίδια.
- Στα υπόλοιπα, η προβαλλόμενη απόσταση C–H μειώθηκε λιγότερο από 50%
  και οι C–C εμφανίστηκαν μεγαλύτεροι, παρότι οι αποθηκευμένοι C δεν κινήθηκαν.
- Μετρήσεις κέντρων πραγματικών glyph bounding boxes στα 1500 px:
  screen C–H ratio ≈0,875 στο αιθάνιο έως ≈0,611 στο μεγαλύτερο αλκάνιο·
  screen C–C ratio ≈1,749 έως ≈1,223 αντίστοιχα. Στα 390 px οι τιμές αλλάζουν
  λόγω fit. Αυτά είναι κέντρα glyphs στην οθόνη, όχι μήκος του ορατού stroke.
- Η υπάρχουσα προσαρμογή μπορεί να μειώνει το μέγεθος χαρακτήρων στα μεγαλύτερα
  μόρια. Δεν πειράχτηκε renderer για αντιστάθμιση αυτών των επιδράσεων.

Άρα το παραδοτέο είναι η εγκεκριμένη δοκιμή MOL με καταγεγραμμένο αποτέλεσμα,
όχι εγγύηση ακριβούς υποδιπλασιασμού των ορατών δεσμών ή αμετάβλητων C–C σε pixels.
Ο χρήστης ενημερώθηκε για αυτή τη διαφορά πριν από την τελική παράδοση.

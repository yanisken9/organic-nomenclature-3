1. Κοινή υπηρεσία πραγματικών glyph bounds/label layout με ελεγμένη ασφαλή
   διαχείριση αποτυχίας, font readiness και cache. Ακριβή bounds να χρησιμοποιούνται

   atom IDs πριν από μετασχηματισμούς. Η συνένωση να αφαιρεί μόνο τα σχήματα
   της ομάδας που αντικαθιστά. Διατήρηση font attributes σε αντικαταστάσειςNH2.
   Καμία νέα ειδική εξαίρεση ανά μόριο. Οι εγκεκριμένοι κανόνες ομοιομορφίας
   οριζόντιων/κατακόρυφων δεσμών και τα πραγματικά χημικά highlights διατηρούνται.
3. Συντηρήσιμη, αναπαραγώγιμη και versioned αλλαγή του JSME module/loader με
   σωστό cache invalidation στην `mulermoc-nom-52.html` και στις πραγματικές
   main lesson διαδρομές. Όποια εφεδρικά masks κριθούν περιττά αφαιρούνται μόνο
   μετά από ειδική σύγκριση της λειτουργίας τους· όχι τυφλή αφαίρεση πολιτικών.
4. Έλεγχος αποδοχής κάθε μελλοντικής MOL προσθήκης: χωρίς contact, ανεπιθύμητη
   πλήρη κάλυψη γραμμής, clipping ή λάθος atom mapping. Θετικές και αρνητικές
   δοκιμές για crowded inputs, χημικός/ονοματολογικός έλεγχος όταν αλλάζουν mappings
   ή δεδομένα, πραγματικά browser checks και ένας consolidatedReviewer.
5. Πριν από ενσωμάτωση/παρουσίαση: πλήρες σχετικό regressionκαι πραγματική
   συμφωνημένη πρόβα, άλλοι υποστηριζόμενοι browsers, zoom extremes, late fonts,
   recovery. Ξεχωριστό πλάνο JSmol lifecycle και ελεγμένου τοπικού fallback με
   γνωστές εκδόσεις εξαρτήσεων για το συνέδριο. Δεν υλοποιήθηκαν αυτά εδώ.

Το συγκεκριμένο τελικό integration patch/file list/cache strategy χρειάζεται
να παρουσιαστεί για έγκριση μετά την επιλογή της προσέγγισης. Το παρόν είναι
έλεγχος εφικτότητας/κινδύνων, όχι άδεια απεριόριστου refactor ή production edits.
